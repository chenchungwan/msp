# Smile Project website

The landing page for the Smile Project iPhone app, with its Privacy Policy and Terms and Conditions.

- `index.html`: landing page
- `privacy.html`: Privacy Policy
- `terms.html`: Terms and Conditions
- `site.css`, `img/`: shared styles and images

Plain static files with no build step. To host with GitHub Pages: Settings → Pages → Deploy from branch → `main`, folder `/ (root)`.
